# **App Name**: Coinbase Hat Studio

## Core Features:

- Photo Upload and Preview: Allow users to upload photos with drag-and-drop, supporting standard formats (JPEG, PNG, WEBP) and providing an immediate preview. Implement file size validation (max 10MB) with clear error messages.
- Manual Hat Positioning: Enable users to manually adjust the hat's position, size, and rotation on the uploaded photo using intuitive controls.
- Hat Overlay: Overlay the provided hat image (PNG with alpha) onto the photo, allowing users to scale, rotate, and reposition the hat for a perfect fit.
- Image Download: Generate and allow users to download the final composite image (PNG) with the hat overlay, maintaining original quality and offering the option to retain the original resolution.
- Automatic Hat Suggestions: Suggest hat sizes to match the detected face. The system acts as a tool suggesting an appropriately sized hat given the dimensions of the face detected by the AI system.

## Style Guidelines:

- Primary color: Coinbase signature blue (#0052FF) to align with the brand's identity. This should be a default style choice.
- Background color: Light gray (#F4F4F4) to create a clean and professional look.
- Accent color: Success green (#05B169) used sparingly for positive feedback and calls to action.
- Primary font: 'Inter' sans-serif for both headings and body text, for a modern, neutral aesthetic. 
- Use simple, outline-style icons to maintain a clean and minimalist design.
- Maintain a clean and minimal layout with ample white space and rounded corners (8px-16px) on cards and buttons.
- Implement subtle, smooth animations (200-300ms ease-in-out) for transitions and interactions to enhance user experience.
